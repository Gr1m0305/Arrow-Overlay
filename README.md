# Arrow Overlay

Draws a line on top of your screen using hotkeys. Runs in the system tray.

- `[` sets point 1
- `]` sets point 2
- `[` + `]` together deletes the line

Right-click the tray icon to change the hotkeys, colour and thickness.

## Build

Run `build.bat`. This creates `bin\ArrowOverlay.exe`.
